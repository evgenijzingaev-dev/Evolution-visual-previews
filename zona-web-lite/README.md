# Zona Web Lite · Haier (неофициальная тестовая сборка)

Простой Android 7.1+ клиент с **одним WebView** вместо тяжёлой оболочки Zona.
Телевизор: Haier LE43K6500SA. Отдельное приложение, существующую Zona не удаляет и не изменяет.

**Внимание:** это НЕ исходная Zona с удалёнными тяжёлыми компонентами.
Это отдельная оболочка для официальных сайтов:
- [Zona для старых ТВ](https://w1.zona.plus/) (перенаправляется на w140.zona.plus)
- [Zona новая](https://w1.zona.im/)

## Возможности
- Android 7.1 / API 25; minSdk 24
- один WebView, без фоновых сервисов, анимаций и аналитики в коде оболочки
- отключённая по умолчанию загрузка сетевых изображений (постеры можно включить из меню)
- cookies и DOM localStorage веб-сайта остаются между запусками
- сохраняется последний URL, кнопка «Продолжить»
- полноценный HTML5 fullscreen на сайте
- MENU — открыть главное меню; BACK — вернуться на страницу назад
- кэш можно очистить без удаления cookie и localStorage

Не гарантируется поддержка всех страниц сайта в старом WebView Android 7.1, управление стрелками во встроенных веб-элементах, сохранение **точной секунды и озвучки** (ими управляет сайт) или меньшее потребление ОЗУ. Внешние данные и код оригинального приложения Zona не используются. Рекламу/видео никто не скачивает или не модифицирует.

## Сборка

GitHub Actions: [Zona Web Lite - build and Android 7 test](https://github.com/evgenijzingaev-dev/Evolution-visual-previews/actions/workflows/zona-web-lite.yml)

Успешная сборка прикрепляет архив **Zona-Web-Lite-Haier-APK** с APK и настоящим скриншотом тестового эмулятора. Откройте последний успешный запуск и скачайте Artifacts.

Локально из папки `zona-web-lite`:

```bash
gradle :app:assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.

## Отличие от оригинальной Zona

Нет оригинального нативного каталога, рекомендаций и внутреннего управления плеером.
Содержимое сайта Zona формируется на стороне веб-сервера и может быть тяжёлым.
Выигрыш в расходе памяти нужно проверять **на самом Haier** через `adb shell dumpsys meminfo com.haier.zonaweblite` и сравнивать с установленной Zona в одинаковом сценарии. Эмулятор не может заменить измерения на телевизоре.

Неофициальное приложение; с Zona не связано.
